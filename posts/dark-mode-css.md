다크 모드는 이제 거의 기본 기능이 되었습니다. 이 블로그에서 쓴 방법을 정리해 봅니다.

## 색상을 변수로 정의하기

모든 색상을 `:root`에 CSS 변수로 모아 두고, 다크 테마에서는 값만 바꿉니다.

```css
:root {
  --bg: #ffffff;
  --text: #1f2328;
}

[data-theme="dark"] {
  --bg: #0f1115;
  --text: #e6e8eb;
}

body {
  background: var(--bg);
  color: var(--text);
}
```

이렇게 하면 컴포넌트마다 다크 모드 스타일을 따로 쓸 필요가 없습니다.

## 시스템 설정 따르기

처음 방문한 사람에게는 운영체제 설정을 그대로 보여주는 것이 자연스럽습니다. `prefers-color-scheme` 미디어 쿼리로 알 수 있습니다.

```js
const dark = matchMedia('(prefers-color-scheme: dark)').matches;
```

## 깜빡임 막기

테마를 정하는 스크립트를 `<head>` 안에 **인라인으로** 넣어야 합니다. 그래야 CSS가 적용되기 전에 테마가 정해져서, 흰 화면이 번쩍이는 현상이 생기지 않습니다.

### 선택 저장하기

사용자가 버튼으로 테마를 바꾸면 `localStorage`에 저장합니다. 사생활 보호 모드에서는 저장소 접근이 실패할 수 있으니 `try/catch`로 감싸 둡니다.

## 정리

1. 색상은 CSS 변수로 관리한다
2. 기본값은 시스템 설정을 따른다
3. 테마 결정 스크립트는 `<head>`에 인라인으로 둔다
