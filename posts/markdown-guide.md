이 글은 블로그의 마크다운 변환기가 지원하는 문법을 모두 보여줍니다.

## 글자 꾸미기

**굵게**, *기울임*, ~~취소선~~, 그리고 `인라인 코드`를 쓸 수 있습니다. __밑줄 두 개__와 _밑줄 하나_도 됩니다.

줄 끝에 공백 두 개를 넣으면  
이렇게 줄이 바뀝니다.

별표를 그대로 쓰고 싶으면 \*역슬래시\*를 앞에 붙입니다.

## 코드 블록

```js
function greet(name) {
  return `안녕하세요, ${name}님!`;
}

console.log(greet('독자'));
```

긴 줄은 코드 블록 안에서만 가로로 스크롤됩니다:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory /Users/someone/projects/my-blog/very/long/path
```

## 표

| 문법 | 예시 | 결과 | 비고 | 지원 |
| :--- | :--- | :---: | --- | ---: |
| 굵게 | `**글자**` | **글자** | 별표 두 개 | O |
| 기울임 | `*글자*` | *글자* | 별표 하나 | O |
| 취소선 | `~~글자~~` | ~~글자~~ | 물결 두 개 | O |
| 코드 | 백틱으로 감싸기 | `코드` | 백틱 하나 | O |
| 파이프 | `a \| b` | a \| b | 역슬래시로 이스케이프 | O |

## 안전하게 표시하기

본문에 HTML을 쓰면 실행되지 않고 글자 그대로 보입니다: <script>alert('hi')</script>

[위험한 링크](javascript:alert(1))는 주소가 `#`으로 바뀌어 아무 일도 일어나지 않습니다.
