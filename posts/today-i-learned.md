클로드 코드와 함께 프레임워크 없이 블로그를 만들어 봤습니다. 직접 만들어 보니 웹페이지를 이루는 세 가지 언어가 각자 어떤 일을 하는지 잘 보였습니다.

## 한눈에 보기

| 언어 | 역할 | 비유 |
| --- | --- | --- |
| HTML | 내용과 구조 | 집의 뼈대 |
| CSS | 모양과 배치 | 인테리어 |
| JavaScript | 동작과 상호작용 | 전기와 수도 |

## HTML: 구조를 만든다

HTML은 페이지에 **무엇이 있는지**를 정합니다. 제목, 문단, 목록, 링크 같은 내용을 태그로 감싸서 의미를 붙입니다.

```html
<header>블로그 이름과 테마 버튼</header>
<main>글 목록이나 본문</main>
<footer>저작권 표시</footer>
```

- `<div>`만 쓰기보다 `<header>`, `<main>`, `<article>` 같은 **시맨틱 태그**를 쓰면 구조가 분명해집니다.
- 화면 낭독기 같은 보조 기술도 이 구조를 읽고 사용자에게 알려줍니다.

## CSS: 보기 좋게 꾸민다

CSS는 HTML이 **어떻게 보일지**를 정합니다. 색, 글꼴, 여백, 배치가 모두 CSS의 몫입니다.

- **CSS 변수**: 색을 `--bg`, `--text` 같은 변수로 모아 두면 다크 모드를 만들 때 값만 바꾸면 됩니다.
- **미디어 쿼리**: 화면 너비에 따라 스타일을 바꿔서 모바일과 데스크톱 모두에서 잘 보이게 합니다.
- **가독성**: 본문 너비를 680px 정도로 제한하고 줄간격을 넉넉히 주니 글이 훨씬 편하게 읽혔습니다.

```css
[data-theme="dark"] {
  --bg: #0f1115;
  --text: #e6e8eb;
}
```

## JavaScript: 움직이게 만든다

JavaScript는 페이지가 **어떻게 동작할지**를 정합니다. 이 블로그에서는 다음 일을 맡았습니다.

1. `fetch`로 마크다운 파일을 불러온다
2. 마크다운을 HTML로 바꿔 화면에 넣는다
3. 태그를 누르면 글 목록을 거른다
4. 버튼을 누르면 다크 모드로 바꾸고 그 선택을 기억한다

```js
const res = await fetch('posts/today-i-learned.md');
const text = await res.text();
```

> 사용자가 쓴 내용을 화면에 넣을 때는 HTML로 해석되지 않도록 조심해야 한다는 것도 배웠습니다.

## 정리

세 언어는 역할이 분명하게 나뉩니다. **HTML로 구조를 세우고, CSS로 꾸미고, JavaScript로 움직이게** 합니다. 역할을 나눠 두면 코드를 고치기도 쉬워집니다. 다음에는 이 블로그에 검색 기능을 붙여 보고 싶습니다.
